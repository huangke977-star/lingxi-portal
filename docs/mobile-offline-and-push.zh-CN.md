# P20 移动端与离线体验

## 1. 已交付范围

- **PWA 离线阅读**：用户在文章、专题或合集页面主动点击“保存离线”后，浏览器会保存当前已成功读取的内容。离线页为 `/offline`，可查看类型、缓存时间、占用空间和过期标记，也可以删除单项或清空全部内容。
- **权限边界**：不缓存 API 响应、上传内容、实时连接或后台管理页面。离线缓存与当前浏览器登录实例绑定，退出登录或切换账号时清空，避免账号之间串读。
- **容量边界**：最多 30 项、最多 25 MB；先保存的内容在达到上限时优先保留，超出项不会写入。缓存超过 7 天显示“可能已过期”，重新联网打开后会以服务器内容刷新。
- **弱网降级**：GET/HEAD 请求有 12 秒超时，并对网络异常、408、429 和 5xx 做最多两次重试。写入类请求不自动重试，避免重复创建或重复扣款。
- **草稿恢复**：文章编辑器原有的本机草稿继续保留；断网时自动保存转为本地状态，恢复网络后会主动重试一次。
- **上传优化**：较大的 JPEG/WebP 图片在浏览器端按最长边 2400 像素、质量约 84% 压缩；PNG、GIF、SVG 和压缩后更大的文件保留原文件，压缩失败不阻断上传。
- **Web Push**：通知包含站内分类、当前账号语言、深链 URL 和去重键。英文账号优先使用英文正文；点击通知会聚焦已有页面并导航到深链。推送服务继续自动清理 404/410 失效订阅。

## 2. 使用和验收

1. 登录后打开一篇有权阅读的文章，点击“保存离线”，再到“我的阅读 -> 离线内容”确认条目出现。
2. 断开网络，直接打开该文章地址；正文仍可查看，评论、点赞、订阅等需要服务器的动作应保持不可用或等待联网。
3. 在离线页删除单条，再清空全部，确认列表与容量统计同步更新。
4. 编辑文章时断网，确认自动保存状态转为本机暂存；恢复网络后等待自动保存完成。
5. 在消息设置中检查浏览器推送权限、服务器未配置、权限被拒绝和已订阅状态提示。推送服务未配置时不能伪造为已开启。

## 3. Android/iOS 评估结论

当前继续使用 PWA，不立即投入原生 Android/iOS。PWA 已覆盖安装、离线内容和 Web Push，维护成本最低。以下任一条件满足后再单独立项：需要系统级后台同步或通话能力、iOS Web Push 到达率持续不足、需要应用商店分发，或真实活跃用户足以覆盖两套原生构建和审核维护成本。

原生化的主要新增成本是 Apple Developer 与 Google Play 开发者账号、双端发布审核、推送证书/密钥、隐私合规材料、离线数据迁移和第三方 SDK 维护；这些不是 PWA 当前运行的前置条件。
