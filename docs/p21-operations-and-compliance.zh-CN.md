# P21 运营韧性与合规

P21 把备份、存储巡检、审计、升级和发布操作整理成可记录的运维闭环。页面入口为超级管理员的“后台管理 → 系统概览”。

## 已实现能力

- **恢复演练**：本地演练会创建数据库与媒体配对备份，读取备份归档并校验数据库、媒体快照和 SHA-256 清单；不会覆盖生产数据库。OSS/R2 演练会在提供商已配置时执行备份上传结果校验，未配置时记录为“阻塞”，不会显示为成功。
- **告警与升级**：系统概览会检查数据库/远端备份失败、磁盘达到预警线、缺失文件和孤立文件。告警有首次发现、最近发现、发生次数、确认和解决状态；处理路径是先确认、保留记录、按备份/磁盘/存储巡检手册处理，再标记解决。
- **审计留存**：审计按业务、安全、服务器三类隔离。默认保留期分别为 180、365、90 天，可由超级管理员调整为 7 至 3650 天。敏感字段由审计写入时脱敏；导出接口仅超级管理员可用，导出最多 10,000 条当前筛选结果，CSV 不包含明文密码、Token 或 Secret。
- **依赖评估**：页面读取 API/Web `package.json` 与生产 Compose 中的当前版本，标记固定版本、范围版本或未读取，并显示升级关注点。生产 API 镜像会携带这些评估所需的只读元数据；“未读取”只表示对应文件在当前运行环境不可见，不表示依赖不可用。该功能是兼容性清单，不会自动升级生产依赖。
- **恢复目标**：页面当前展示系统内置的 RPO、RTO、媒体完整性和接口降级目标，用于对照演练结果；这些目标目前是服务端固定值，尚未提供后台配置入口。
- **压测脚本**：`scripts/p21-load-test.mjs` 默认只请求 `/health`，不会写入数据。可通过 `P21_BASE_URL`、`P21_LOAD_PATHS`、`P21_CONCURRENCY`、`P21_DURATION_SECONDS` 和 `P21_ACCESS_TOKEN` 调整，输出请求数、成功率、RPS、P50/P95/最大延迟和错误样本。
- **页面压测**：系统概览的“只读压测”只能选择服务端白名单接口，任务在 API 后台异步执行，结果写入“最近演练记录”，不会把 Docker 权限或任意 URL 暴露给浏览器。
- **发布与恢复**：发布、迁移、API/Web 重建和容器清理仍由仓库 Compose、GitHub Actions、1Panel 或 SSH 执行；Web API 没有宿主机 Docker 权限。
- **备份列表维护**：数据库备份支持逐份删除和勾选后批量删除；批量删除会在服务端统一加锁，并同时清理对应的媒体快照与校验记录。

## OSS/R2 当前边界

没有 OSS/R2 凭据不影响本地备份、配对媒体快照、清单和哈希校验，也不占用远端网络资源。真实异地上传和从远端对象下载恢复，必须先配置 `BACKUP_ENCRYPTION_KEY`、Bucket、区域/Account ID 和最小权限访问密钥，然后在“备份策略”中连接测试，最后执行 OSS 或 R2 恢复演练。验收记录必须区分“本地通过”和“远端待配置”。

## 推荐验收顺序

1. 在系统概览点击“检查告警”，确认检查记录出现。
2. 点击“本地演练”，确认记录为“通过”，详情包含备份名、媒体校验和 `nonDestructive: true`。
3. 在无 OSS/R2 配置时点击或查看远端演练，确认记录为“阻塞”，而不是“通过”。
4. 修改审计保留期并保存，执行“立即清理”，确认删除数量和上次清理时间被记录。
5. 进入审计日志，使用筛选后点击“导出”，确认下载的是脱敏 CSV；普通管理员只能查看允许的业务审计，不能导出安全/服务器审计。
6. 执行只读压测：`$env:P21_BASE_URL="https://你的域名"; $env:P21_LOAD_PATHS="/api/health"; $env:P21_DURATION_SECONDS="15"; pnpm p21:load-test`。生产环境先从并发 2 至 4 开始，禁止把写接口放进默认压测路径。
7. 也可以在“后台管理 → 系统概览 → P21 运营韧性 → 只读压测”选择接口、并发数和持续时间，点击“开始压测”；任务完成后在“最近演练记录”点击“详情”查看指标和错误样本。
8. 依赖升级前先备份数据库和媒体，保留当前 API/Web 镜像标签；升级失败按发布手册回滚镜像，迁移只执行向前兼容变更。

## 运行边界

恢复演练默认是非破坏性的归档验证，不等价于把生产数据库覆盖恢复。正式灾备验收仍需在隔离数据库和隔离媒体目录完成一次真实下载、解密、导入和抽样访问，并记录实际 RTO/RPO。应急联系人、外部服务账号和密钥只保存在受保护的运维系统，不写入仓库。
