# P23 AI 网关使用说明

## 入口与权限

超级管理员登录后进入“后台管理 -> AI 配置”。普通管理员不能读取或修改 AI 配置，也不能查看调用记录。

## 连接配置

- 供应商：按服务商选择 `OpenAI Compatible`、`Anthropic` 或 `Google`。
- 接口地址：填写服务商的 API 根地址，不要填写 API Key。
  - OpenAI 兼容：例如 `https://api.openai.com/v1`。系统会请求 `/chat/completions`。
  - Anthropic：例如 `https://api.anthropic.com`。系统会请求 `/v1/messages`。
  - Google：例如 `https://generativelanguage.googleapis.com/v1beta`。系统会请求所选模型的 `:generateContent`。
- 模型名称：填写服务商实际提供的模型 ID。
- API Key：只发送到服务端并加密保存，浏览器不会再次读到原文；留空保存时表示保留原密钥。
- 启用 AI：只有保存完整连接配置并启用后，文章助手等用户功能才会发起请求。连接测试不要求先打开启用开关。

保存后点击“测试连接”。成功会显示耗时，并在“调用记录”中生成一条连接测试记录；失败只显示安全的 HTTP 状态或连接错误，不展示服务商响应正文。

## 资源保护

- 全站并发：同一时间全站最多进行的 AI 请求数。当前服务器默认推荐为 2。
- 单用户并发：同一账号同一时间最多进行的 AI 请求数。默认推荐为 1。
- 最大输出 tokens：限制单次返回量，避免异常请求长期占用资源。
- 请求超时：超过时间后主动中止请求，已占用的并发会在 `finally` 中释放，Redis 中也有超时租约兜底。
- 全站每日请求上限：按 UTC 日期统计的全站请求数；填 0 表示不限。并发释放不会把已经消耗的每日额度退回。

推荐先保持全站 2、单用户 1、超时 60 秒、最大输出 2000。当前配置不运行本地模型，不会在服务器常驻 Ollama、向量数据库或其他 AI 服务。

## 用量与费用

供应商返回 token 用量时，系统会保存输入、输出和总 tokens。输入价和输出价按“每百万 tokens”填写，例如 `0.15` 表示每百万 tokens 计价 0.15 个所选币种；填 0 表示只统计 tokens，不估算费用。系统保存的是微单位整数，日志不会保存提示词、生成正文或 API Key。

调用记录用于排查连接、超时、额度和服务商失败。失败记录只保留有限长度的安全错误摘要；不应把密码、令牌或其他敏感信息写入操作名称。
