# 聊天右键菜单与双向删除调整

## 修改范围

- PC 端通过消息右键菜单打开操作项，移动端继续保留触摸操作入口。
- 右键菜单优先显示在鼠标右下侧并保留间距，空间不足时切换到左上侧，避免指针直接落在操作项上。
- 菜单选项取消边框，鼠标悬浮时轻微高亮。
- 通过精简后的“选择”进入现有多选模式，并在底部操作抽屉中执行删除。
- 多选状态下点击整条消息即可切换选中状态，选择控件统一固定在消息行左侧。
- 允许会话任一参与者将所选消息从双方记录中永久删除，包括系统消息。
- 系统消息、文字、图片、文件及通话提示均可执行仅自己删除或双向删除；清空会话也覆盖全部消息类型。
- PC 端的清空聊天、删除聊天移入联系人操作气泡，移动端继续保留标题栏入口。
- 聊天气泡、右键菜单、好友菜单、表情面板和确认弹窗使用与账号头像菜单一致的高可读磨砂表面。

## 安全规则

- 双向删除仍要求操作者属于对应会话。
- 撤回仍仅限发送者本人、普通消息及发送后两分钟内。
- 清空聊天和删除聊天仍只影响当前账号。
