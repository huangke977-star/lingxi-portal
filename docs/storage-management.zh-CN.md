# 存储管理

## 入口与权限

- 系统概述中的“文件存储分布”提供存储健康摘要和“存储管理”入口。
- 详细页面路径为 `/admin/storage`。
- 系统概述、扫描结果、文件预览、回收站和扫描策略仅超级管理员可访问。

## 扫描范围

扫描覆盖以下持久化目录：

- 全站背景图片
- Logo 与 PWA 图标等站点资源
- Android 安装包
- 用户头像
- 文章图片
- 聊天附件

扫描会把磁盘文件与数据库记录逐项比对，并标记：

- **文件缺失**：数据库仍有记录，但磁盘文件不存在。
- **孤立文件**：磁盘文件存在，但数据库没有对应记录。
- **大小不一致**：数据库记录的文件大小与磁盘实际大小不同。

上传临时目录中的文件在 24 小时内受到保护，不会被判定为可清理孤立文件。单次扫描最多检查 50,000 个文件，扫描通过异步文件接口执行，不会在系统概述刷新时递归遍历目录。

## 回收站

- 只有扫描结果中的孤立文件可以移入回收站。
- 执行移动前，后端会再次检查文件是否已经被业务数据引用。
- 文件会移动到原上传卷内的 `.trash` 隐藏目录，不会立即物理删除。
- 可以在保留期内恢复到原位置，或者手动永久删除。
- 到达清理时间后，后台任务会物理删除文件及回收站记录。

## 自动扫描与预警

默认配置：

- 每日自动扫描：启用
- 执行时间：`04:00`
- 时区：`Asia/Shanghai`
- 回收站保留：7 天
- 磁盘预警阈值：75%

磁盘使用率超过阈值或扫描发现缺失文件时，系统会向超级管理员发送系统消息。同类预警最短间隔为 24 小时，避免重复通知。

## API

- `GET /admin/system/storage`：存储概览
- `POST /admin/system/storage/scans`：启动扫描
- `GET /admin/system/storage/scans/:id`：读取扫描状态
- `GET /admin/system/storage/issues`：分页查询异常文件
- `GET /admin/system/storage/issues/:id/file`：预览或下载孤立文件
- `POST /admin/system/storage/issues/:id/trash`：移入回收站
- `GET /admin/system/storage/trash`：分页查询回收站
- `POST /admin/system/storage/trash/:id/restore`：恢复文件
- `DELETE /admin/system/storage/trash/:id`：永久删除文件
- `GET /admin/system/storage/configuration`：读取扫描策略
- `POST /admin/system/storage/configuration`：保存扫描策略

## 验证步骤

1. 使用超级管理员登录，进入“系统概述”，确认文件存储卡片出现“存储管理”入口。
2. 打开存储管理并执行“立即扫描”，确认页面显示扫描中，完成后自动刷新结果。
3. 切换异常类型和文件分类，确认搜索与分页有效。
4. 对可预览的孤立图片执行预览和下载。
5. 将测试孤立文件移入回收站，确认原位置不可见、回收站出现记录。
6. 恢复文件并重新扫描，确认文件重新出现在孤立文件列表中。
7. 再次移入回收站并永久删除，确认文件和回收站记录均消失。
8. 修改自动扫描时间、保留天数和预警阈值，保存后刷新页面确认配置保留。
9. 使用管理员角色访问 `/admin/storage`，确认返回无权限。
