# 文章可靠编辑与统一搜索

## 功能范围

第三阶段在现有文章中心和全站搜索基础上增加以下能力：

- 编辑器停止输入 1.8 秒后自动保存，并显示等待、保存中、已保存和本机暂存状态。
- 自动保存失败时将文字草稿保留在当前浏览器；重新打开编辑页后可以恢复或丢弃。
- 未上传图片不会写入服务器或浏览器存储，恢复草稿时会提示重新选择图片。
- 自动保存、手动保存、发布和版本恢复都会生成不可变文章快照。
- 相同内容不会重复生成快照；每篇文章最多保留最近 50 个自动保存版本，手动、发布和恢复版本不受此限制。
- 恢复旧版本会把内容恢复为新草稿并新增一个 `restore` 快照，不修改或覆盖旧快照。
- 发布预览复用正式阅读页的正文渲染、标题、分类、标签和权限信息。
- 搜索文章、用户、导航和工具，继续执行原有文章可见性、角色和服务器入口权限过滤。
- 支持中文、完整拼音和拼音首字母检索，并提供分类筛选、综合/最新/热门排序和分页。
- 登录用户明确提交搜索时记录最近搜索并累计热门搜索；输入联想不会计数。

## 数据结构

迁移 `20260807173000_add_content_reliability_and_search` 新增：

- `article_versions`：文章不可变快照、版本号、来源、变更字段、编辑人和内容哈希。
- `search_history`：账号级搜索历史，按账号和标准化关键词去重。
- `search_keyword_stats`：全站热门搜索累计数据。
- `users`、`articles`、`portal_entries` 的 `search_text` 与 `search_pinyin` 标准化检索字段。

API 启动时只回填检索字段为空的旧记录，每批 100 条；已有索引内容不会被重复改写。

## 接口

文章版本：

- `POST /articles/autosave`
- `POST /articles/:id/autosave`
- `GET /articles/:id/versions`
- `GET /articles/:id/versions/:versionId`
- `POST /articles/:id/versions/:versionId/restore`

搜索：

- `GET /search/public`
- `GET /search/visible`
- `GET /search/hot`
- `GET /search/history`
- `POST /search/history`
- `DELETE /search/history/:id`
- `DELETE /search/history`

## 验收重点

1. 新文章输入后无需点击保存即可生成草稿，并将地址切换到编辑地址。
2. 断开 API 或制造保存失败后，状态显示“已保存在本机”，恢复网络后可以重试。
3. 历史版本能查看变更字段和完整正文，恢复后旧版本仍存在且新增恢复版本。
4. 发布预览中的 Markdown、图片、标题颜色、分类和标签与正式阅读页一致。
5. 使用中文、完整拼音和首字母分别搜索同一内容，均能返回有权限查看的结果。
6. 私密文章、无权角色文章和服务器入口不能出现在无权用户的搜索结果中。
7. 最近搜索可以逐条删除或全部清空，输入联想不会增加搜索次数。
8. 390px 移动端下编辑器、版本窗口、搜索建议和结果列表没有横向溢出。

## 回滚说明

Web/API 可以一起回滚到上一镜像。新增表和字段是兼容性结构，回滚应用时可以暂时保留；确认不再需要且已备份后，再单独删除迁移新增结构。
